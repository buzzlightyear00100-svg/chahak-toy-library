# Chahak Toy Library website

One-page website for Chahak Toys Khilona Library, a free toy library run by Tapovan Trust in Jawahar Nagar, Sri Ganganagar.

## Files

- `index.html` is the whole site (text, styles and animations, with the English/Hindi toggle).
- `logo.jpg` and `photos/` hold the images and the short video.

## Editing

Open `index.html` in any text editor, or edit it right on GitHub with the pencil icon. To preview, open `index.html` in a browser. If GitHub Pages is turned on, changes go live a minute or two after they are saved.
